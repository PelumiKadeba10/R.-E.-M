Event Management Web Application Front-end Repository

This is a full-stack web application for managing events. The project utilizes React for the frontend and Flask for the backend, providing a seamless user experience for viewing events

Features
- view events

Tech Stack
Frontend:
- React
- Tailwind CSS

Backend:
- Flask
- MongoDB
